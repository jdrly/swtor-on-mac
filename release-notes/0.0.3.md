## SWTOR on Mac 0.0.3

A Play button.

- **Play SWTOR**, the big button in the window once SWTOR on Mac is installed (and at the end
  of an install), opens the official SWTOR app, so you can start right away. If the launcher
  or the game already runs, it brings it to the front instead (*Show SWTOR Launcher*).
- It is off, with the reason under it, while the official app is missing, the launcher hook
  needs a repair, or an install or uninstall runs.
- New in Settings: *Quit SWTOR on Mac after launching* (off by default).
