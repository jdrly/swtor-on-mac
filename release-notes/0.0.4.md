## SWTOR on Mac 0.0.4

Key binds for non-US keyboard layouts.

- New in Settings, **Keyboard > Game keys by keyboard position** (off by default). On a Czech,
  French or other layout whose number row doesn't type digits, the game showed key binds and
  action bars as *+ ě š č ř ž ý á í é* or *& é " ' (*. Turn this on and the game sees every key
  by its position on a US keyboard: the number row is 1–0 in key binds and action bars. Typing
  in chat still uses your layout (ě š č with Czech, dead keys and Shift included).
- Settings points it out when your current layout's number row doesn't type 1–0.
- It changes binds on QWERTZ layouts (Czech, German) too: the key labelled Z is *Y* in the game,
  and the other way round, because a US keyboard has Y there.
- How: a build of Wine's Mac driver (`winemac.so`) with a new option, from CodeWeavers'
  CrossOver 24.0.7 sources and a small patch (LGPL, in the repository under `patches/`). It is
  used only while the setting is on; otherwise the engine keeps its own driver.

Change it with the launcher and the game closed. The setting installs the driver itself, so it
works without a Reinstall; *Reinstall to update* in the window, as after every update, brings
the rest of the installed setup to 0.0.4.
