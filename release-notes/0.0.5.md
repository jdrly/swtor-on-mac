## SWTOR on Mac 0.0.5

More video memory for the game on 8, 16 and 24 GB Macs.

- The game gets more video memory on 8/16/24 GB Macs: 2/3/4 GB instead of 1/2/3 GB (d9mt
  `c2a819d`). Textures should stay sharp in busy places such as fleet and crowded planets. Macs
  with more memory already got 4 GB, as the official Mac app gives.
- **Settings > Video Memory Profile** says what each setting gives the game. Raise it if your
  Mac has memory to spare; lower it if macOS runs short of memory.
- The compiled-shader cache is kept: no extra stutter after the update.

Click *Reinstall to update* in the window, as after every update, so the game uses the new
d9mt.
