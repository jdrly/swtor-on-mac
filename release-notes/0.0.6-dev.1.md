## SWTOR on Mac 0.0.6-dev.1 (development build)

A test build of the next version, for measuring before a release. It is not offered as an
update; install it by hand. The next public version (0.0.6) is offered over it as usual.

**What's new (d9mt `7975e2e`, branch `dev`):**
- **Less memory traffic per frame.** d9mt picks each render pass's load and store actions from
  what the pass does. It no longer loads and stores attachments whose contents are a known
  clear and that nothing writes, such as the 2048×2048 color target SWTOR's shadow passes bind
  with color writes off (about 32 MB per shadow pass). Clear-only passes go away. MSAA resolves
  are done by the rendering pass itself. Anything that is drawn into is still kept. Expected
  effect: lower GPU load and power, fewer render passes. Visuals stay the same.
- **Optional pipeline wait budget** (off): `d9mt.pipelineWaitBudgetMs` caps how long a frame
  waits for shaders still compiling.
- **`STATS` line once a second** with Debug Logging: fps, frame times, slow frames, render
  passes, the attachment traffic saved, compile waits, memory.

**Development build:**
- A *Development build* badge in the window and in About.
- **Debug Logging is on by default.** It costs a little performance; turn it off in Settings if
  you like.
- No automatic update checks. *Check for Updates…* works.
- `session-report.sh` (in the app's Resources, also in Collect Logs) sums up a session and
  compares two:

  ```
  R="/Applications/SWTOR on Mac.app/Contents/Resources"
  "$R/session-report.sh" --keep              # the last session, and keep a copy of its log
  "$R/session-report.sh" --compare A.log B.log
  ```

To install: quit SWTOR, copy the app from the DMG over the one in Applications, open it, and
click *Update to 0.0.6-dev.1* (Reinstall).
