## SWTOR on Mac 0.0.6-dev.3 (development build)

A test build of the next version, for measuring before a release. It is not offered as an
update; install it by hand. The next public version (0.0.6) is offered over it as usual.

**What's fixed since 0.0.6-dev.2 (d9mt `9d23889`, branch `dev`):**
- **SWTOR no longer hangs at a black screen at startup with Debug Logging on.** dev.2's new
  re-clear attribution (the `RESTORE` lines) had d9mt record a command each time the game
  locked a texture. SWTOR does that from its texture streaming threads as well, at the same
  time as it renders, so two threads wrote into d9mt's command queue at once. A d9mt thread
  then crashed, and the game sat at a black screen. With Debug Logging off, that code never
  ran. d9mt now records nothing for those locks. A new test that streams textures from a second
  thread while presenting frames, with Debug Logging's settings, hung dev.2 every time and
  passes with this build.

**What's new:**
- With Debug Logging, the once-a-second `STATS` line also has `attMs` (the render thread's CPU
  time in the attachment load/store optimization, ms per second), `clrFold` and `clrPass`
  (clears per frame that were folded into the next pass, or needed a pass of their own).
  `session-report.sh` sums them up. Together with the compile waits, they show whether stutter
  comes from that optimization or from shaders being compiled (a cold shader cache).
- To compare with the optimization off, put `no_attach_opt` on its own line in
  `~/Library/Application Support/SWTOR on Mac/prefix/drive_c/d9mt/flags.txt` while the game
  runs (Debug Logging on), and remove the line to turn it back on.

The rest is as in 0.0.6-dev.2. The shader cache stays warm: the winemetal bridge is the same
as in 0.0.5.

**Development build:**
- A *Development build* badge in the window and in About.
- **Debug Logging is on by default.** It costs a little performance; turn it off in Settings if
  you like.
- No automatic update checks. *Check for Updates…* works.
- `session-report.sh` (in the app's Resources, also in Collect Logs) sums up a session and
  compares two:

  ```
  R="/Applications/SWTOR on Mac.app/Contents/Resources"
  "$R/session-report.sh" --keep              # the last session, and keep a copy of its log
  "$R/session-report.sh" --compare A.log B.log
  ```

To install: quit SWTOR, copy the app from the DMG over the one in Applications, open it, and
click *Update to 0.0.6-dev.3* (Reinstall).
