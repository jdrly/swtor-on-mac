## SWTOR on Mac 0.0.6-dev.4 (development build)

A test build of the next version, for measuring before a release. It is not offered as an
update; install it by hand. The next public version (0.0.6) is offered over it as usual.

**What's new since 0.0.6-dev.3:**
- **A new Settings window.** It no longer outgrows the screen: a sidebar on the left lists the
  sections (Graphics, Game, Keyboard, Play Button, Updates, Troubleshooting), and the selected
  section's settings are shown next to it, as in Finder or System Settings. The window opens at
  760 × 520 points, can be resized, and opens on the section you used last. Use ↑ and ↓ in the
  sidebar to switch sections. Every setting is still there, with the same explanations.
  *Changes take effect the next time the game starts* now appears once, in small text, under
  the sections whose settings the game reads (Graphics, Game, Keyboard, Troubleshooting).

The rest is as in 0.0.6-dev.3: the same d9mt (`9d23889`), and the shader cache stays warm (the
winemetal bridge is the same as in 0.0.5).

**Development build:**
- A *Development build* badge in the window and in About.
- **Debug Logging is on by default.** It costs a little performance; turn it off in Settings if
  you like.
- No automatic update checks. *Check for Updates…* works.
- `session-report.sh` (in the app's Resources, also in Collect Logs) sums up a session and
  compares two:

  ```
  R="/Applications/SWTOR on Mac.app/Contents/Resources"
  "$R/session-report.sh" --keep              # the last session, and keep a copy of its log
  "$R/session-report.sh" --compare A.log B.log
  ```

To install: quit SWTOR, copy the app from the DMG over the one in Applications, open it, and
click *Update to 0.0.6-dev.4* (Reinstall).
