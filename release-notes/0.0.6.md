## SWTOR on Mac 0.0.6

Less GPU memory traffic, a new Settings window, and better logs for bug reports.

- **Less GPU memory traffic** (d9mt `68c7190`). The graphics driver no longer reads and writes
  every render target in full for every part of a frame when it doesn't have to. That saves
  roughly 0.6 to 1 GB of memory traffic per frame in busy scenes. It helps most on M1, M2 and
  M3 Macs with high shadow quality or anti-aliasing. The game looks exactly the same.
- **A new Settings window.** A sidebar lists the sections (Graphics, Game, Keyboard, Play
  Button, Updates, Troubleshooting), as in System Settings. The window fits on any screen, can
  be resized, and opens on the section you used last. Every setting is still there.
- **Better logs for stutter reports.** With Settings > Troubleshooting > *Debug Logging* on,
  the log now records frame times, slow frames and shader compiles once a second, and
  *Collect Logs…* adds a short summary of your last game session. Leave Debug Logging off
  unless you're reporting a problem: it costs a little performance.

After updating, open SWTOR on Mac and click *Update to 0.0.6* in the window (with the game
closed), as after every update, so the game uses the new graphics driver.

The compiled-shader cache is kept, so there should be no extra stutter after the update. If
the first few minutes in a new area do stutter, the cache is being rebuilt; that settles by
itself.
