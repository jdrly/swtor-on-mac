## SWTOR on Mac 0.1.0-dev.1 (development build)

A test build of the next version, for testing before a release. It is not offered as an
update; install it by hand. The next public version (0.1.0) is offered over it as usual.

**What's new:**
- **A new Wine engine: CrossOver 26.3 with Wine 11**, the same engine SWGL on Mac uses
  (athei's build of CodeWeavers' CrossOver 26.3). It replaces CrossOver 24.0.7 (Wine 9). There
  is no choice between engines: this version uses only the new one. The graphics driver is the
  same as in 0.0.6 (d9mt `68c7190`), and its shader cache is kept.
- **Game keys by keyboard position** (Settings > Keyboard) works as before, with a new build of
  the Mac driver for the new engine.
- Game Mode, Retina, vsync, the video memory profiles, Debug Logging and the session report
  work as before. The session report and *Collect Logs…* now name the Wine engine a session
  ran on.

**Updating from 0.0.6:**
- After copying the app, open SWTOR on Mac and click *Update to 0.1.0-dev.1* (Reinstall) with
  the launcher and the game closed. It downloads the new engine once (about 235 MB) and updates
  your existing Wine prefix for it, which takes under a minute. Your game settings, key
  bindings and SWTOR on Mac's settings stay.
- Until you do, the game keeps running on the old engine, and Settings asks for the update
  first.
- If the update fails, everything is put back as it was. The old engine is removed only once
  the update has gone through.
- Going back to 0.0.6 works: copy 0.0.6 over this app, open it and click Reinstall.

**Please report problems:** turn on Settings > Troubleshooting > *Debug Logging* (on by default
in this build), play, quit, then use *SWTOR on Mac > Collect Logs…* and send the zip. It
includes the session report. To compare a session with one on 0.0.6:

```
R="/Applications/SWTOR on Mac.app/Contents/Resources"
"$R/session-report.sh" --keep              # the last session, and keep a copy of its log
"$R/session-report.sh" --compare A.log B.log
```

**Development build:**
- A *Development build* badge in the window and in About.
- **Debug Logging is on by default.** It costs a little performance; turn it off in Settings if
  you like.
- No automatic update checks. *Check for Updates…* works.

To install: quit SWTOR, copy the app from the DMG over the one in Applications, open it, and
click *Update to 0.1.0-dev.1* (Reinstall).
