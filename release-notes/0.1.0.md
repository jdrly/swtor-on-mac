## SWTOR on Mac 0.1.0

A new Wine engine, smoother mouse-look, and leftover Wine processes cleaned up after you quit.

### A new Wine engine: CrossOver 26.3 with Wine 11
SWTOR on Mac now runs the game on CrossOver 26.3 with Wine 11, the same engine SWGL on Mac uses.
It replaces CrossOver 24.0.7 with Wine 9. The graphics driver is the same as in 0.0.6, so your
compiled-shader cache is kept and there should be no extra stutter after the update. Game Mode,
Retina, vsync and the video memory profiles work as before.

### Smoother mouse-look
While you hold a mouse button to turn the camera, the game now gets every movement of the mouse
as it happens, straight from the mouse, instead of once per screen refresh and a refresh late.
The pointer stays where it is while you turn and comes back where you clicked when you let go.
- It is on by default. You can turn it off in Settings > Mouse > *Raw mouse-look*.
- *Mouse-Look Speed* (0.5× to 3×) sets how fast the camera turns. At 1× it turns as fast as
  before: SWTOR on Mac matches your pointer speed during the first second of mouse-look.
- Holding the right mouse button no longer causes a small hitch. The game stays in direct
  presentation the whole time, which the Metal HUD shows as *Direct*.

### Leftover Wine processes are cleaned up
After you quit, the official launcher's helper could start SWTOR on Mac's Wine again for a
moment, which left a `winedevice.exe` running in the background. SWTOR on Mac now waits for that
helper and ends what is left, without touching Broadsword's own programs.

### Better Debug Logging
With Settings > Troubleshooting > *Debug Logging* on, the log now also records how evenly the
game draws its frames, how busy its threads are, and what mouse-look does. *Collect Logs…* sums
it up in the session report. Leave Debug Logging off unless you're reporting a problem: it costs
a little performance.

### Game keys by keyboard position
Settings > Keyboard > *Game keys by keyboard position* works as before, with a new build for the
new engine.

### After updating
Open SWTOR on Mac and click *Update to 0.1.0* in the window, with the launcher and the game
closed. It downloads the new engine once, about 235 MB, and updates your Wine setup for it in
under a minute. Your game settings, key bindings and SWTOR on Mac's settings stay. Until you do
this, the game keeps running on the old engine and Settings asks for the update first. If the
update fails, everything is put back as it was.
