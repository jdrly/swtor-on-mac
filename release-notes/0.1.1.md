## SWTOR on Mac 0.1.1

Less work for the GPU at high resolutions, and less stutter the first time you play after an update.

### Less GPU load at high resolutions
The graphics driver, d9mt `6fa5df7`, now lets the GPU keep textures and the screen compressed in
memory, and waits less between the steps that draw a frame. In testing at 4K in a busy Imperial
Fleet, the game kept the same frame rate while the GPU used about a third less power. This
matters most where the GPU is the limit: base M-series chips, and fanless MacBook Airs, which
slow down when they get warm.

### Less stutter the first time you play after an update
d9mt now remembers which pipelines (the GPU programs for each way the game draws) the game uses,
and prepares them in the background while you log in, so they are ready when you walk into a
busy place instead of being built in the middle of a frame.
- Your first session on 0.1.1 makes that list. From then on, every game start prepares it.
- After an update that makes d9mt rebuild its shader cache, the first session stutters much
  less than before. In testing, the time the game spent waiting for pipelines went from about
  7 seconds to under 1 second.
- The list is kept next to d9mt's shader cache. If macOS clears that folder to free space, the
  next session makes it again.

### Graphics driver fixes
d9mt now converts two kinds of Direct3D 9 shader code correctly for Metal, and carries out some
image copies and fills (`StretchRect`, `ColorFill`) that it used to skip. SWTOR doesn't use
these, so the game looks the same as before.

### More in Debug Logging
With Settings > Troubleshooting > *Debug Logging* on, the session report in *Collect Logs…* also
shows how many pipelines were ready in time, and which of the GPU savings were in use. Leave
Debug Logging off unless you're reporting a problem: it costs a little performance.

### After updating
Open SWTOR on Mac and click *Update to 0.1.1* in the window, with the launcher and the game
closed. It takes under a minute and downloads nothing: it puts the new graphics driver into your
Wine setup. Until you do this, the game keeps running on 0.1.0's driver. Your game settings, key
bindings and SWTOR on Mac's settings stay, and so does your compiled-shader cache, so there is
no extra stutter after the update.
