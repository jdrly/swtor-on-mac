## SWTOR on Mac 0.1.4

A newer graphics driver: no more pink frames or GPU errors right after the game starts, pipelines prepared with less work, a clearer log when the GPU drops work, and a fix in the Mac driver's debug output.

### No more pink frames or GPU errors when the game starts
Right after the game started, the graphics driver could let go of the screen's image before the
GPU had finished with it. That could show pink frames or end in a GPU error. d9mt (`a779f54`) now
keeps the image until the GPU is done.

### The graphics driver does less work for the same frames
- Each pipeline (the GPU program for one way the game draws) is now built and recorded once,
  instead of up to three times, and found again faster.
- Changing what kind of shapes the game draws no longer forces a pipeline lookup.
- The list of pipelines the driver prepares in the background now survives a crash or a force
  quit of the game.
- Fixes in rarely used drawing paths (old-style effects without a texture, unused resource
  slots).

### A clearer log when the GPU drops work
When the GPU throws away a piece of work (a GPU fault), `wine.log` can now say so with a
`D9MT-GPU-LOST` line. The driver checks a sample of the GPU's work, so not every fault gets a
line; macOS's own log still has them. That helps when you report graphics problems with
*Collect Logs…*.

### One time: the pipeline list is made again
The driver now records pipelines in a new way, so the list it prepares in the background starts
over once. Your first session after the update may stutter a little more in busy places while it
records them again; from the second session on, they are prepared while you log in, as before.
Your compiled-shader cache is kept.

### Debug: the THREADCPU wineserver figure was 41.7× too small
The Mac driver's THREADCPU debug line (`warn+threadcpu`, for performance reports) showed the
wineserver's CPU time 41.7 times too small on Apple silicon: macOS reports a process's CPU time
in clock ticks of 41.67 ns, which the driver read as nanoseconds. It now converts them. Nothing
changes for playing; only performance reports that compare that figure are affected
(`patches/winemac-swtor-mouse.patch`).

### After updating
Open SWTOR on Mac and click *Update to 0.1.4* in the window, with the launcher and the game
closed. It takes under a minute and downloads nothing (from 0.0.6 it downloads the new Wine engine
once, about 235 MB). Your game settings, key bindings and SWTOR on Mac's settings stay.
