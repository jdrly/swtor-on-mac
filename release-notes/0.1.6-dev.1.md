## SWTOR on Mac 0.1.6-dev.1 (development build)

A test build of 0.1.4 with a newer graphics driver that ends a hung game instead of leaving it frozen, and Metal's archive usage index in *Collect Logs…*.

### A hung game ends instead of freezing
When the GPU stopped finishing the game's work (a GPU hang), the game could stay frozen while
the graphics driver waited again and again in 10-second cycles. The driver, d9mt `08827cb`, now
ends the game after about 10 seconds of submitted work not completing, and `wine.log` says so
with a `D9MT-GPU-HUNG` line. If that happens, choose *Collect Logs…* before you start the game
again: a new game start replaces `wine.log`. `D9MT_GPU_HUNG=continue` brings the old behaviour
back for testing; it is no workaround for a frozen screen. This doesn't keep a rare graphics
error from freezing the whole screen (the known issue in 0.1.4).

### Metal's archive usage index in Collect Logs
`system-info.txt` in *Collect Logs…* now also shows the size of Metal's archive usage index for
the game (compiled shaders are cached separately), and the number of `MDB_MAP_FULL` events that
the game and Wine reported in the last 2 hours. Those events may concern an earlier index or
another cache, so it's unknown how full the current index is. It also notes that other
CrossOver-based apps share these caches.

### Not in this build: the 0.1.5 hotfix
This test build does not include the canary hotfix planned for 0.1.5. *Check for Updates* will
not offer 0.1.5, because this development build sorts above it. To return to 0.1.5 once it is
available, quit the game, the launcher and SWTOR on Mac, download the 0.1.5 DMG and replace the
app in Applications. Open it and click *Update to 0.1.5* to put that version's graphics driver
in place.

### After updating
Quit the SWTOR launcher and the game, open SWTOR on Mac and click *Update to 0.1.6-dev.1* in the
window. That puts the new graphics driver in place. Your game settings, key bindings and SWTOR on
Mac's settings stay.
