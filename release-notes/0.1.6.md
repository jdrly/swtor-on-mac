## SWTOR on Mac 0.1.6

A new graphics driver that fixes the black screen on macOS 26 and the magenta icons on M4 Macs, ends a game frozen by a GPU hang, and keeps your compiled shaders from 0.1.5.1.

### No black screen on macOS 26
On macOS 26 the game could stay black after the first loading screen while its sound played on.
The graphics driver labelled its compiled shaders with a newer version of Metal's shader format
than macOS 26 accepts, so macOS 26 refused every one of them. The driver now labels them for the
macOS it runs on (d9mt `4dbe7fa`). On macOS 27 the label stays as it was. The fix was tested on
macOS 27 only. On macOS 26 the shaders now carry the label Apple's own Metal tools give them.

### No magenta icons on M4 Macs
On an M4 Mac, icons such as those in Collections could show as magenta squares while they loaded.
The game reads some textures before it has written anything into them, and the driver handed it
whatever was in that memory. Windows gives such a texture zeros, and the driver now does the same,
so those icons stay dark until the game fills them (d9mt `8c17836`).

### A game frozen by a GPU hang now ends
When the GPU never finishes the work the game sent it, a GPU hang, the game used to sit frozen
until you force quit it. Now the driver waits about 10 seconds, writes a `D9MT-GPU-HUNG` line to
`wine.log` and ends the game (d9mt `f48680a`). If that happens, choose *Collect Logs…* before you
start the game again. The next game start replaces `wine.log`.

### Other driver fixes
- A draw whose vertex range ran past the end of its vertex buffer could make the driver read past
  its copy of that buffer and crash the game. The driver now ends the copy at the buffer's end
  (d9mt `ee5d2d8`).
- 0.1.5's GPU error check is here in a reworked form (d9mt `610df1b`). Every frame shown on the
  screen still carries it, scaled and MetalFX frames included. Work that shows no frame gets a
  check of its own only after a quarter of a second without one.

### Your compiled shaders stay
On macOS 27, updating from 0.1.5.1 keeps the shaders the driver has already compiled. The driver
now keys its shader cache on the code that compiles them, and 0.1.6 compiles them to the same
bytes as 0.1.5.1, so it takes over 0.1.5.1's cache (d9mt `b532e9c`). On macOS 26 the driver
compiles them once more, because 0.1.5.1's were the ones macOS 26 refused. The first session
after the update may stutter a little more in busy places while it does.

### Collect Logs
- A failed game start keeps its `wine.log`. SWTOR on Mac keeps the logs of the last 4 starts.
- The run time of the last 10 game starts and how each one ended, the game's language, and the
  official launcher's own logs are in the zip. Account names, e-mail addresses and your user name
  are removed from the launcher's logs, and a log that still holds one is left out.
- `system-info.txt` shows how full Metal's archive usage index for the game is, and says it's
  full only when macOS logged that in the last 2 hours.
- The message after collecting is shorter and has a *Close* button. Finder opens only from
  *Show in Finder*. The message points you to a post in #swtor-on-mac-issues on the
  [SWTOR on Mac Discord](https://discord.gg/AnV3fZWz2b).

### The session report counts only time on screen
The session report in the Collect Logs zip used to average every second of the session, also
the seconds the game window was hidden by Cmd-Tab, another Space or minimizing. The driver slows
the game down while it's hidden, so the report showed a lower frame rate than you saw. It now
counts the frame rate, frame times and hitches only while the window showed the game, and lists
the hidden seconds on a line of their own.

### A new app icon
Crossed blades on the window's jump-point background, with the window's wordmark across them.

### From 0.1.5.1
The notice, the notification and the *Collect Logs…* line for a launcher that macOS doesn't
allow to run in the background are all in 0.1.6. If the game hangs without a window after you
press Play, open System Settings > Login Items and turn on Star Wars - The Old Republic under
*App Background Activity*. If you're updating from 0.1.3 or older, 0.1.6 also brings everything
in [0.1.4](https://github.com/jdrly/swtor-on-mac/releases/tag/v0.1.4).

### After updating
Open SWTOR on Mac and click *Update to 0.1.6* in the window, with the launcher and the game
closed. From 0.1.4 or newer it takes under a minute and downloads nothing. It puts the new
graphics driver in place. From 0.1.3 or older it also removes the old helper, and from 0.0.6 it
downloads the Wine engine once, about 235 MB, which may take longer. Your game settings, key bindings and SWTOR on Mac's settings stay.
