## SWTOR on Mac 0.1.8

A big graphics update under the hood: the game's shaders are now built for your macOS, a few things draw the way the game intends, and the first start after updating takes a bit longer, once.

### Your first start takes a bit longer, once
After the update the game builds its shaders again, one time. You'll notice it at character
select and the first loading screen, which take a little longer than usual. After that it's
smooth, and the game uses its saved shaders again, as before. A place you haven't visited since
the update may build a few more the first time you go there.

It's on purpose. Every change to the shader compiler went into this one release, so you only sit
through it once.

### Graphics built for your macOS
The graphics driver now builds the game's shaders the way Apple's own tools do for the macOS
you're on, with macOS 26 and macOS 27 each getting their own (d9mt `f5439a6`). 0.1.6 got rid of
the black screen on macOS 26 by relabelling the shaders. This is the proper fix behind it. What
you see in the game stays the same.

### Fixed
- **Bright dots along edges**: the game draws some objects more than once and expects every pass
  to land on exactly the same spot. Now they do, which may get rid of the single bright dots that
  could show up along some edges. Still seeing them? Tell me where
- **Older effects**: fog, flat-colored objects, shiny or reflective surfaces and some of the
  game's older drawing now come out the way the game asks for them. If something looks worse than
  in 0.1.7, tell me where
- **Old graphics caches**: on the first start the driver deletes the caches earlier versions left
  behind, so they stop taking up space on your Mac

### Good to know
- **On macOS 26?** Please tell me how it goes. I develop on macOS 27, and this release hasn't run
  on macOS 26 yet. If you get a black screen or the game closes at the start, choose
  *Collect Logs…* in SWTOR on Mac and send me the zip, and I'll help you get going again
- **Broadsword's DirectX 12 test client** now comes with every install of the game, on a Mac too.
  SWTOR on Mac doesn't support it and hasn't tested it, so keep starting the game with
  *Play SWTOR*
- **Banded shadows on characters in close-ups**: there's a new test switch for those. It's off,
  changes nothing for you, and isn't a fix. Testers try it first

### If something goes wrong
If the game freezes, closes, or the Mac logs you out, open SWTOR on Mac, choose *Collect Logs…* before
you start the game again, and send the zip.

### After updating
Open SWTOR on Mac and click *Update to 0.1.8* in the window, with the launcher and the game closed.
From 0.1.4 or newer it takes under a minute and downloads nothing. Your game settings, key
bindings and SWTOR on Mac's settings stay. Then expect the longer first start (see above).
