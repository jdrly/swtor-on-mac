## SWTOR on Mac 0.1.9

A smaller update: quitting keeps the game's pipeline cache, mouse-look lets go when the game is on another desktop, and your shaders carry over from 0.1.8.

### Nothing recompiles
The shaders the game compiled with 0.1.8 carry over, so there's no slower first start this time 🎉

### Smoother starts after quitting
When you quit, the game now saves Metal's pipeline cache before it closes, so the next start has
less to build. Before, a quit could lose that cache and leave a temporary file of about 9 MB
behind each time. Those files get cleaned up now too (d9mt `9b64581`).

### Fixed
- **Mouse-look stuck on another desktop**: with *Raw mouse-look* on, switching to another desktop
  (Space) while holding the mouse button could leave the pointer frozen there. Now you get the
  pointer back, and the camera turns again once you're back on the game's desktop

### For testers
- The session report's A/B/A row "Game thread CPU" is now "Process CPU (PACE)", because it always
  measured the whole process. The per-frame row says "device blocked" where it said "of it
  waiting"

### After updating
Open SWTOR on Mac and click *Update to 0.1.9* in the window, with the launcher and the game closed.
Your game settings, key bindings and SWTOR on Mac's settings stay.
